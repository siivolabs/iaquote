Cycle de données

  1. ImporterLe CSV reste la source commerciale.
  2. Enrichir automatiquementTous les nouveaux produits sont placés dans une file et traités en arrière-plan.
  3. ContrôlerLe moteur de règles vérifie les compatibilités connues.
  4. ArgumenterQwen3 formule une explication à partir des produits sélectionnés.

Garde-fous

  • Une référence absente du CSV n'entre pas dans le devis.
  • Un prix ou une marge n'est jamais demandé à l'IA.
  • Un contrôle inconnu reste affiché comme inconnu.
  • Le vendeur valide toujours la proposition finale.

Ce qui se passe après un import

  1. File persistanteLes 300 produits peuvent être planifiés sans bloquer la page.
  2. Traitement séquentielLes requêtes sont espacées pour ménager la source.
  3. Cache localLes fiches déjà vérifiées ne sont pas téléchargées à nouveau.

Comportement réseau

L'application interroge uniquement la source définie dans la configuration privée, espace les requêtes et met le résultat en cache. Un échec sur un produit n’interrompt pas les suivants.

Une fiche incertaine est marquée À contrôler et n'est pas utilisée quand le filtre « vérifié uniquement » est actif.
